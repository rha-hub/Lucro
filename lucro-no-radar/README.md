# Lucro no Radar

Sistema de controle financeiro e precificação para pequenos negócios.

## Arquivos

- `Lucro_no_Radar_Sistema_Completo.xlsx` — planilha principal com abas de configuração, catálogo, vendas, recebimentos, despesas, precificação, painel, caixa, metas e checklist mensal.

## Como usar

1. Baixe o arquivo XLSX e abra no Microsoft Excel moderno.
2. Preencha as células de configuração e cadastre os produtos/serviços.
3. Registre vendas, recebimentos e despesas nas abas apropriadas.
4. Consulte precificação, painel, caixa e metas para acompanhar o negócio.

**Importante:** Os resultados são estimativas de gestão, não substituem a contabilidade. A planilha foi projetada para Excel moderno e pode exigir recálculo das fórmulas ao abrir.
